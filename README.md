# init-study

AI가 빠르게 발전하면서, 편해진 만큼 스스로 생각하는 힘은 점점 약해지는 느낌이 들었다.
그래서 처음부터 다시, 기초를 내 손으로 탄탄하게 다지기 위해 시작한 프로젝트다.

## 작성 규칙
- 노트는 직접 쓴다. AI는 내 답을 검증받는 용도로만 쓴다.
- 주제 하나 = md 파일 하나. 해당 분야 폴더에 `kebab-case.md`로 만든다. (예: `cs/network/tcp-vs-udp.md`)
- 정리한 파일은 분야 README에 링크를 건다.
